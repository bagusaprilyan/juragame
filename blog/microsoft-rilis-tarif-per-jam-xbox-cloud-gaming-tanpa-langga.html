Microsoft Rilis Tarif Per Jam Xbox Cloud Gaming Tanpa Langganan Game Pass

Oleh: Admin Jura•8 Min Baca
#microsoft #rilis #tarif #xbox #cloud

📰 Sumber Berita

Artikel ini disusun ulang dalam Bahasa Indonesia berdasarkan laporan GameSpot. Semua fakta mengacu pada sumber asli. Kami menulis ulang dengan konteks untuk gamer Indonesia.

Ringkasan Poin Utama

  • Microsoft telah secara resmi mengumumkan kebijakan baru terkait layanan penyiaran awan mereka, **Xbox Cloud Gaming**.
  • Langkah strategis ini diperkenalkan dengan jadwal ekspansi ketersediaan yang direncanakan mulai menyasar lebih banyak pemain pada bulan November mendatang.
  • Paket waktu bermain berbasis durasi ini secara resmi dinamai oleh Microsoft dengan sebutan **cloud playtime packs**.

Microsoft telah secara resmi mengumumkan kebijakan baru terkait layanan penyiaran awan mereka, Xbox Cloud Gaming. Perusahaan teknologi tersebut kini mengungkap rincian biaya yang akan dibebankan kepada para pemain yang ingin memanfaatkan layanan cloud gaming tanpa perlu memiliki keanggotaan Xbox Game Pass. Untuk saat ini, skema tarif tersebut baru tersedia secara eksklusif bagi para pengguna yang terdaftar di dalam program Xbox Insiders, yang merupakan program pengujian cuma-cuma dan dapat diikuti oleh siapa saja secara terbuka. Keputusan ini menjadi penanda penting bahwa Microsoft mulai membuka pintu ekosistem permainan berbasis cloud miliknya kepada khalayak yang lebih luas di luar ekosistem pelanggan bulanan konvensional.

Langkah strategis ini diperkenalkan dengan jadwal ekspansi ketersediaan yang direncanakan mulai menyasar lebih banyak pemain pada bulan November mendatang. Microsoft menyebut daftar harga awal ini sebagai harga peluncuran perkenalan (introductory launch pricing), sebuah penegasan yang memberikan indikasi kuat bahwa besaran tarif tersebut masih dapat mengalami penyesuaian pada masa depan. Selain menghadirkan sistem kuota waktu berbayar, raksasa teknologi ini juga menyiapkan alternatif gratis dengan dukungan iklan untuk anggota program insider, sembari menerapkan kebijakan baru berupa pembatasan kuota pemakaian per bulan bagi pelanggan Game Pass aktif.

Rincian Paket Cloud Playtime Packs dan Skema Tarif Berbayar

Paket waktu bermain berbasis durasi ini secara resmi dinamai oleh Microsoft dengan sebutan cloud playtime packs. Melalui kehadiran paket ini, para pengguna yang tidak memiliki langganan Game Pass dapat membeli sejumlah jam bermain tertentu yang dapat digunakan secara fleksibel sesuai kebutuhan mereka masing-masing.

Dalam pengumuman resminya, Microsoft merinci tiga pilihan paket durasi waktu yang dapat dibeli oleh konsumen:

  1. Paket 10 jam bermain dengan tarif sebesar $4.
  2. Paket 25 jam bermain dengan tarif sebesar $8.
  3. Paket 50 jam bermain dengan tarif sebesar $12.

    4. Bagi para pemain yang memutuskan untuk membeli salah satu dari paket cloud playtime packs tersebut, Microsoft menjanjikan pengalaman bermain yang jauh lebih optimal dan nyaman. Pembeli paket berbayar ini dipastikan akan mendapatkan akses ke layanan cloud gaming tanpa interupsi iklan komersial apa pun. Selain bebas dari gangguan iklan, para pengguna paket ini juga memperoleh berbagai keuntungan tambahan, seperti waktu tunggu (wait times) antrean server yang jauh lebih singkat serta kualitas streaming gambar dan audio yang lebih tinggi dibandingkan akses standar. Format ini dinilai cocok bagi pemain yang hanya ingin menyelesaikan judul game tertentu dalam durasi terbatas tanpa terikat tagihan berulang setiap bulan.

    Opsi Akses Gratis Didukung Iklan Lewat Program Xbox Insiders

    Sebagai pelengkap dari paket berbayar, Microsoft juga mengeksplorasi model monetisasi lain agar layanannya dapat dicicipi tanpa perlu mengeluarkan biaya di muka. Sebuah versi Xbox Cloud Gaming yang didukung tayangan iklan kini telah disediakan secara khusus bagi para anggota Xbox Insiders yang tidak memiliki langganan Game Pass.

    Melalui skema gratis ini, pemain yang tergabung dalam program pengujian insider dapat langsung mengakses dan memainkan game dari katalog cloud dengan konsekuensi menyaksikan jeda tayangan iklan sebelum atau selama sesi permainan berlangsung. Mengingat Xbox Insiders merupakan keanggotaan bebas biaya yang terbuka bagi semua orang, skema ini menjadi kesempatan menarik bagi pemain yang ingin menjajal kapabilitas teknologi komputasi awan Microsoft. Namun, berbeda dengan pembeli paket berbayar, pengguna versi beriklan ini tidak mendapatkan prioritas antrean sehingga kemungkinan harus bersabar menghadapi waktu tunggu yang lebih lama ketika antrean server sedang padat.

    Perubahan Kuota Waktu untuk Pelanggan Game Pass Mulai November

    Kabar yang paling memicu perhatian dari pengumuman ini justru tertuju pada para pengguna yang saat ini telah aktif berlangganan Xbox Game Pass. Pasalnya, perubahan besar akan mulai diterapkan pada layanan cloud gaming untuk para anggota Game Pass terhitung mulai bulan November mendatang.

    Dalam kebijakan anyar tersebut, Microsoft akan memberlakukan batasan kuota waktu bulanan mengenai berapa jam pelanggan dapat memanfaatkan layanan cloud gaming. Apabila jatah jam bermain dalam satu bulan tersebut telah habis digunakan, para pelanggan diberikan opsi untuk membayar biaya tambahan demi membuka waktu bermain ekstra. Rincian kuota durasi waktu yang disertakan dalam masing-masing tingkatan langganan Game Pass adalah sebagai berikut:

    • Game Pass Ultimate: Mendapatkan alokasi waktu cloud gaming sebanyak 15 jam per bulan.
    • Game Pass Premium: Mendapatkan alokasi waktu cloud gaming sebanyak 10 jam per bulan.
    • Game Pass Essential: Mendapatkan alokasi waktu cloud gaming sebanyak 5 jam per bulan.

    Microsoft menyatakan bahwa pihaknya memahami langkah ini merupakan sebuah perubahan yang bermakna (meaningful change), terutama bagi konsumen yang rutin memanfaatkan akses awan untuk bermain game sehari-hari. Meski demikian, pihak perusahaan memperkirakan bahwa kebijakan kuota jam ini hanya akan berdampak langsung pada sekitar 4% dari total basis pelanggan Game Pass. Terkait proyeksi tersebut, Microsoft belum membagikan rincian data metodologi maupun dasar perhitungan yang digunakan untuk menghasilkan estimasi angka 4% itu.

    Wacana Kustomisasi Layanan Game Pass oleh CEO Asha Sharma

    Perkembangan seputar restrukturisasi layanan cloud ini berjalan beriringan dengan laporan penting lainnya mengenai masa depan layanan langganan Microsoft. Baru-baru ini tersiar kabar bahwa CEO Xbox, Asha Sharma, tengah mempertimbangkan perombakan besar-besaran terhadap struktur layanan Game Pass secara menyeluruh.

    Rencana perombakan tersebut berfokus pada pemberian keleluasaan kepada para pemain untuk merancang atau membangun sendiri paket Game Pass mereka (build your own Game Pass). Di bawah konsep ini, pelanggan dapat secara bebas memilih fitur-fitur spesifik yang mereka butuhkan dan memangkas fitur yang tidak mereka inginkan agar biaya berlangganan menjadi lebih sesuai kebutuhan. Kehadiran paket jam terpisah seperti cloud playtime packs serta kuota waktu bermain tampak sejalan dengan visi modular yang sedang dipertimbangkan oleh kepemimpinan Asha Sharma, di mana fitur komputasi awan ke depannya dapat menjadi komponen opsional.

    Konteks Kebijakan Baru Ini Bagi Komunitas Gamer Indonesia

    Bagi komunitas penggemar game di Indonesia, perubahan skema yang diumumkan Microsoft ini menghadirkan sudut pandang tersendiri yang perlu dipahami secara saksama. Konsep pembelian paket jam terpisah memberikan fleksibilitas baru bagi gamer lokal yang mungkin hanya memiliki waktu bermain terbatas di akhir pekan dan enggan membayar biaya langganan bulanan secara penuh.

    Namun, ada beberapa aspek praktis yang perlu dicermati oleh gamer tanah air:

    • Terkait ketersediaan resmi infrastruktur server lokal maupun konversi harga paket dalam mata uang Rupiah, saat ini masih belum ada konfirmasi resmi dari pihak Microsoft.
    • Mengingat program Xbox Insiders dapat diakses secara gratis oleh siapa saja, pemain di Indonesia yang tertarik mencoba paket waktu bermain atau versi beriklan ini dapat mendaftar ke program tersebut, kendati performa streaming tetap bergantung pada stabilitas jaringan internet ke server terdekat.
    • Bagi gamer Indonesia yang saat ini sudah berlangganan Game Pass Ultimate, pembatasan 15 jam per bulan perlu disikapi dengan memperhitungkan waktu bermain jika sering mengandalkan fitur cloud, karena alokasi tersebut setara dengan rata-rata setengah jam permainan per hari.
    • Bagi kalangan yang memanfaatkan Game Pass murni untuk mengunduh dan memainkan game secara lokal di konsol Xbox atau PC, aturan ini tidak perlu dikhawatirkan karena proses bermain secara luring tidak memotong kuota waktu cloud.

    Kesimpulan

    Kebijakan baru yang diperkenalkan Microsoft melalui paket cloud playtime packs dan pembatasan kuota durasi menandai era baru dalam pengelolaan operasional Xbox Cloud Gaming. Di satu sisi, model bayar per jam dan opsi gratis dengan iklan memperluas fleksibilitas bagi pemain yang tidak ingin terikat langganan penuh Game Pass. Di sisi lain, pemberlakuan kuota bagi pelanggan langganan aktif menjadi penyesuaian baru bagi pengguna reguler komputasi awan, sembari menunggu realisasi konsep kustomisasi yang sedang dirancang oleh manajemen di bawah Asha Sharma.
